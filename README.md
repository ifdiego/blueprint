# blueprint

Backend engineering building blocks in Go.

Blueprint is a collection of practical implementations, examples, and experiments focused on backend engineering using Golang.

The goal is to explore and document common backend concepts, tools, and architectural patterns through small, independent, and reusable implementations.

## Topics
- Authentication & Authorization
- REST APIs & gRPC
- Databases & Migrations
- HTTP Middleware
- Logging & Observability
- Caching
- Infrastructure
- Testing
- Software Architecture

## Philosophy
- Keep implementations small and focused.
- Prefer Go's standard library when possible.
- Follow Go best practices and idiomatic patterns.
- Include tests and practical examples.
- Keep components independent whenever possible.

This project is a work in progress. New implementations and topics will be added over time.
